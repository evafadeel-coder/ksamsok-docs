 # K-samsök – Officiell Dokumentation

Välkommen till den öppna dokumentationen för **K-samsök**, Riksantikvarieämbetets nationella söktjänst för kulturarvsinformation. Här hittar du allt du behöver för att förstå, använda och integrera K-samsök i dina egna system och tjänster.

Dokumentationen är öppen för alla och uppdateras löpande.

---

## 📘 Vad är K-samsök?

K-samsök är ett API som samlar och tillgängliggör kulturarvsdata från museer, arkiv, myndigheter och andra kulturarvsinstitutioner. Tjänsten gör det möjligt att:

- söka och hämta objektdata
- integrera kulturarvsinformation i webbplatser och appar
- bygga vidare på öppna data
- länka samman kulturarvsresurser via gemensamma standarder
